# Demonstration 1: scRNA-seq Simulation Evaluation

## Introduction

In single-cell RNA sequencing (scRNA-seq), evaluating the quality of
simulated count data is important before testing analysis tools such as
clustering, batch correction, or differential expression algorithms.

This tutorial shows how to evaluate synthetic scRNA-seq data
step-by-step using **`scSimEval`** without needing any artificial ground
truth.

------------------------------------------------------------------------

## 1. Loading the Package and Example Dataset

`scSimEval` includes pre-packaged real and simulated scRNA-seq count
matrices (`example_scrna`):

``` r
library(scSimEval)

# Load packaged scRNA-seq example data
data(example_scrna)

# Examine dimensions and structure
cat("Reference scRNA-seq dimensions:", dim(example_scrna$ref), "\n")
#> Reference scRNA-seq dimensions: 60 80
cat("Simulated scRNA-seq dimensions:", dim(example_scrna$sim), "\n")
#> Simulated scRNA-seq dimensions: 60 80
cat("Cell types represented:", levels(example_scrna$cell_types), "\n")
#> Cell types represented: TypeA TypeB
cat("Batches represented:", levels(example_scrna$batch_info), "\n")
#> Batches represented: Batch1 Batch2
```

The dataset consists of: \* `ref`: Feature-by-cell matrix of real
experimental scRNA-seq read counts (60 genes $`\times`$ 80 cells). \*
`sim`: Feature-by-cell matrix of simulated counts generated by a
simulation method. \* `cell_types`: Factor of cell type labels. \*
`batch_info`: Factor of technical batch identifiers.

------------------------------------------------------------------------

## 2. Step-by-Step Category Evaluation

#### 2.1 Distribution Properties & Summary Measures (Categories 1 and 2)

We evaluate how closely the simulated gene expression distributions
match the real reference data using
[`evaluate_simulation_accuracy()`](https://kabilanbio.github.io/scSimEval/reference/evaluate_simulation_accuracy.md):

``` r
unimodal_res <- evaluate_simulation_accuracy(
  ref_data          = example_scrna$ref,
  sim_data          = example_scrna$sim,
  compute_bivariate = FALSE,
  verbose           = FALSE
)

# Inspect statistical distance metrics for library size
lib_summary <- subset(unimodal_res$metrics_summary_table, Property == "library_size")
head(lib_summary, 6)
#>                    Category     Property        Metric        Value
#> 1 Distributional Properties library_size           MAD 1.500000e+01
#> 2 Distributional Properties library_size            KS 2.125000e-01
#> 3 Distributional Properties library_size           MAE 1.506250e+01
#> 4 Distributional Properties library_size          RMSE 1.571504e+01
#> 5 Distributional Properties library_size            OV 8.269394e-01
#> 6 Distributional Properties library_size Bhattacharyya 1.188839e-04
```

#### 2.2 Cell Clustering and Concordance (Category 3)

We evaluate whether the simulated data preserves distinct cell types in
unsupervised and supervised clustering using
[`evaluate_clustering_metrics()`](https://kabilanbio.github.io/scSimEval/reference/evaluate_clustering_metrics.md):

``` r
clust_res <- evaluate_clustering_metrics(
  data       = example_scrna$sim,
  cell_types = example_scrna$cell_types,
  ref_data   = example_scrna$ref
)

# Preview clustering concordance metrics
cat("Average Silhouette Width (Simulated):", round(clust_res$silhouette, 4), "\n")
#> Average Silhouette Width (Simulated): 0.0278
cat("Davies-Bouldin Index:", round(clust_res$davies_bouldin, 4), "\n")
#> Davies-Bouldin Index: 5.1752
cat("Adjusted Rand Index (ARI):", round(clust_res$ARI, 4), "\n")
#> Adjusted Rand Index (ARI): 0.0671
cat("Normalized Mutual Information (NMI):", round(clust_res$NMI, 4), "\n")
#> Normalized Mutual Information (NMI): 0.0884
```

#### 2.3 Batch Effects and Confounder Mixing (Category 4)

We test whether technical batch differences are properly mixed without
masking biological differences using
[`evaluate_batch_metrics()`](https://kabilanbio.github.io/scSimEval/reference/evaluate_batch_metrics.md):

``` r
batch_res <- evaluate_batch_metrics(
  data       = example_scrna$sim,
  batch_info = example_scrna$batch_info,
  cell_types = example_scrna$cell_types,
  verbose    = FALSE
)

# Preview batch mixing metrics
cat("Batch Shannon Entropy:", round(batch_res$shannon_entropy, 4), "\n")
#> Batch Shannon Entropy: 0.9796
cat("Principal Component Regression (PCR R2):", round(batch_res$pcr_r2, 4), "\n")
#> Principal Component Regression (PCR R2): 0.0121
cat("Cross-Batch Transfer Accuracy:", round(batch_res$cross_batch_accuracy, 4), "\n")
#> Cross-Batch Transfer Accuracy: 0.6125
```

#### 2.4 Differential Expression (DEG) Fidelity (Category 5)

We assess marker gene effect sizes and top marker overlap using
[`evaluate_deg_fidelity()`](https://kabilanbio.github.io/scSimEval/reference/evaluate_deg_fidelity.md):

``` r
deg_res <- evaluate_deg_fidelity(
  ref_data      = example_scrna$ref,
  sim_data      = example_scrna$sim,
  ref_celltypes = example_scrna$cell_types,
  sim_celltypes = example_scrna$cell_types
)

# Display DEG summary metrics
```

#### 2.5 Trajectory and Lineage Dynamics (Category 6)

We infer developmental pseudotime and lineage branching directly from
scRNA-seq expression counts using
[`evaluate_trajectory_metrics()`](https://kabilanbio.github.io/scSimEval/reference/evaluate_trajectory_metrics.md):

``` r
traj_res <- evaluate_trajectory_metrics(
  ref_data       = example_scrna$ref,
  sim_data       = example_scrna$sim,
  cell_types_ref = example_scrna$cell_types,
  cell_types_sim = example_scrna$cell_types
)

cat("Pseudotime Spearman Correlation:", round(traj_res$pseudotime_correlation, 4), "\n")
#> Pseudotime Spearman Correlation: 1
cat("Lineage Tree Branch Height RMSE:", round(as.numeric(traj_res$tree_height_rmse), 4), "\n")
#> Lineage Tree Branch Height RMSE: 1.8672
```

## 3. Master Unimodal Pipeline: `evaluate_simulation_accuracy`

Instead of running individual steps, execute the entire unimodal
evaluation suite in a single coordinated command:

``` r
eval_res <- evaluate_simulation_accuracy(
  ref_data          = example_scrna$ref,
  sim_data          = example_scrna$sim,
  elapsed_time      = 12.5,
  memory_mb         = 340.2,
  compute_bivariate = FALSE,
  verbose           = FALSE
)

# Preview tidy evaluation summary
head(eval_res$metrics_summary_table)
#>                    Category     Property        Metric        Value
#> 1 Distributional Properties library_size           MAD 1.500000e+01
#> 2 Distributional Properties library_size            KS 2.125000e-01

#> 5 Distributional Properties library_size            OV 8.269394e-01

```
